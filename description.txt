A Munchies Addon

This mod works as a consumable tracker for a lot of mods.
You need to enable Munchies mod to run this mod. 

Supported mods and consumables list: https://docs.google.com/document/d/1B16_GKP1VO_R8pksHzbDrPtvQiNz0KQc4BOWs170jIg/edit?usp=sharing
